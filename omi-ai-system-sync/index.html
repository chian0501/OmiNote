Omi AI System Sync

用途

Omi AI System Sync 是 Omi 個人使用的私人同步工具。規劃將 Omi 私人 GitHub repo 中的 59 份指定文件及 1 份清單檔（manifest），單向同步到 Omi 本人 Google Drive 的私人資料夾「AI_System」。

使用範圍

  • 僅供 Omi 本人使用，不對外提供服務，不開放他人登入或使用。
  • 透過 Google OAuth 存取 Omi 本人的 Google Drive。
  • 申請的 Google 授權範圍為完整 Drive 權限（https://www.googleapis.com/auth/drive，Google 列為受限範圍）。程式另以固定的檔案 ID 白名單限制自身操作；但請注意，Google 授權本身並不限於這些檔案。
