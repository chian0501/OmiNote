# O-Ne Tools

O-Ne 字卡工具入口與編輯器集合。

## 目前內容
- `index.html`：工具入口
- `registry.json`：工具清單與狀態
- `move-card.html`：移動卡編輯器
- `move-card-mapping.json`：移動卡欄位 mapping

## 使用方式
1. 開啟 `index.html`。
2. 在入口頁選擇要製作的字卡。
3. 目前「移動卡」已可使用。
4. 移動卡可動態增減站點、每段切換實線／虛線，並輸出白色版／橘色版透明 PNG。

## 工具入口整理原則
- 一個功能只留一個入口。
- 移動卡不另拆跨國版，跨國需求用每段實線／虛線處理。
- 選項卡不另拆 2 項版，之後在編輯器內增減項目。
- 挑戰任務不拆接受／放棄版，之後在同一編輯器內切換。
- 對話卡已確認為正式卡，後續會整合 Omi／涅特／Kuma／Nomi／NPC／雙人與表情選擇。
- 玩家 1 為移動卡同系藍色，玩家 2 為紅色。

## 維護規則
- 後續新工具或版本更新，直接更新 `O-Ne-Tools/` 內對應檔案。
- 新增工具時，同步更新 `index.html` 與 `registry.json`。
- 不另建平行工具包。
