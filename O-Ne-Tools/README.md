# O-Ne Tools

O-Ne 字卡工具入口與編輯器集合。

## 目前可使用
- 一般卡
- 觸發卡
- 常駐卡
- 移動卡
- 選項卡
- 對話卡
- 評分卡
- 焦點／說明內容卡
- 縮圖品牌框

## 候選測試
- 效果卡 V0.1.8 CANDIDATE：依正式施工圖分離外框、色塊、文字與語意裝飾，中央影片區維持透明。
- 片尾結算卡 V0.1.1 CANDIDATE：QST-03／FORMAL V1.1＋Omi 擴充，支援 1–8 列自由增減、Icon 替換、欄位名稱預設／自訂、左側觀眾互動問題／下一影片模式；訂閱圓框預設關閉，並保留透明背景、設定 JSON 與 Nomi／Kuma 顯示切換。

## 使用方式
1. 開啟 `index.html`。
2. 在入口頁選擇要製作的字卡。
3. 各編輯器可直接輸出 PNG；是否含背景依工具設定。

片尾結算卡的欄位與安全框定義另見 `settlement-card-mapping.json`。正式 PSD 只作來源，生成器不會覆蓋 Drive 母檔。

## 全工具視覺硬規則
- **主底板／卡體底色固定 80% 透明度（opacity = 0.80）。**
- 只有底板底色套用 80%；**不是整張卡片一起 80%**。
- 外框、狀態標籤、識別色條、圖示、文字、選項列與其他前景元件維持各自正式透明度，不得跟著整體變淡。
- 新增任何字卡工具時，必須先檢查此規則再標示可使用。

## 工具入口整理原則
- 一個功能只留一個入口。
- 移動卡不另拆跨國版，跨國需求用每段實線／虛線處理。
- 選項卡不另拆 2 項版；可自由增減選項，每一項可獨立切換亮／暗，允許同時亮多項。
- 挑戰任務不拆接受／放棄版，之後在同一編輯器內切換。
- 觸發卡 EVENT／DONE!／FAIL 在同一編輯器切換。
- 常駐卡 MISSION／DONE!／FAIL 在同一編輯器切換。
- 對話卡已確認為正式卡，後續整合 Omi／涅特／Kuma／Nomi／NPC／雙人與表情選擇。
- 玩家 1 為移動卡同系藍色，玩家 2 為紅色。
